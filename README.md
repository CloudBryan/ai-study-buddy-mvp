# AI Study Buddy MVP (CS4680 Prompt Engineering)

## Overview
An AI-powered web application built to help college students comprehend difficult lecture notes and generate custom interactive practice quizzes using advanced prompt engineering patterns.

## Features
- **Concept Explainer (Persona Pattern):** Uses an enthusiastic, structured tutor persona (Professor Alex) and the Feynman Technique to break down complex subjects with real-world analogies.
- **Quiz Generator (Few-Shot Pattern):** Ingests study notes and outputs structured multiple-choice questions with answer keys and explanations based on predefined examples.
